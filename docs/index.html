A calculator that speaks UDP.

A small client–server app in pure Python. The client sends 12 * 7, the server checks it and replies 84, with rate limiting and protection against abuse.

How it works

One UDP packet goes out, one comes back. Both sides check the input, but the server never trusts the client.

Ask

The client asks for two numbers and an operator, and checks them locally.

Send

It sends one UDP message: <num1> <op> <num2>.

Check

The server checks the rate limit, then validates the format, range and operator.

Reply

The server sends back the result, or a message that starts with ERROR:.

Built with security in mind

UDP has no connections and no handshake, so the server must protect itself. These are the defenses.

✅

Validation on both sides

The client checks input for a good experience. The server checks again: format, integer range −9999…9999, operator and division by zero.

⏱️

Rate limit per IP

10 requests per 30 seconds for each IP address. The key is the IP only, so a client cannot bypass the limit by opening new sockets.

🔇

Silent drop

A rate-limited request gets no reply. A spoofed source address cannot use the server to flood a victim (UDP reflection).

🧹

Memory cleanup

Idle clients are removed from the rate-limit table, so a flood of fake addresses cannot fill the memory.

🏠

Local by default

The server listens on 127.0.0.1. You must choose --host 0.0.0.0 to open it to the network.

🧱

Never crashes

Bad bytes, a bad format and network errors are handled. The server continues to run.

Install & run

You need Python 3.8 or later. There is nothing to install: the project uses only the standard library.

1 · Get the code
git clone https://github.com/yoavbvd/Python-Projects.git
cd Python-Projects/udp-calculator
2 · Terminal 1: start the server
python3 server.py
3 · Terminal 2: start the client
python3 client.py

On Windows, use python instead of python3.

Options
# accept clients from your LAN
python3 server.py --host 0.0.0.0 --port 9090
python3 client.py --host 192.168.1.20 --port 9090
Run the tests
python3 -m unittest discover -s tests -v
